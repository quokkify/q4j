# Q4J Core

Core types, formatting, generation, and utility APIs shared by Q4J modules.

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/core):

```kotlin
dependencies {
    implementation("dev.quokkify:core:0.6.2")
}
```

See the [Q4J module catalog](../../README.md) for the complete list of modules and common setups.

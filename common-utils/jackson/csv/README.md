# Q4J Jackson CSV

CSV parsing and conversion utilities for Q4J.

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/jackson-csv):

```kotlin
dependencies {
    testImplementation("dev.quokkify:jackson-csv:0.6.2")
}
```

See the [Q4J module catalog](../../../README.md) for the complete list of modules and common setups.

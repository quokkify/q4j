# Q4J Jackson CSV

CSV parsing and conversion utilities for Q4J.

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/q4j-jackson-csv):

```kotlin
dependencies {
    testImplementation("dev.quokkify:q4j-jackson-csv:0.5.1")
}
```

See the [Q4J module catalog](../../../README.md) for the complete list of modules and common setups.

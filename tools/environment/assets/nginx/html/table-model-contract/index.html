Table model contract fixtures

Each page is a self-contained fixture demonstrating what the Q4J table model verifies. Open a page to see a live table you can drive with the Selenide table elements.

  • Classic table variants

    Plain, dynamic, flex, and horizontal legacy tables; delayed rows, remount, header skipping, missing cells.

  • Custom and styled grid adapters

    Div/ARIA/headerless grids, nested grid isolation, repeated headers, async row restoration.

  • Classic table edge cases

    Duplicate headers, header inside tbody, and nested table isolation.

  • Table queries

    Zero-based indexing, conditions, unique rows, native waits, header reorder, string-first lookups.

  • Table assertions and embedded controls

    Header/row/cell assertions, buttons, inputs, selects, links, and contenteditable semantics.

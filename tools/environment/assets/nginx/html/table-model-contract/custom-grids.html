Custom and styled grid adapters

Verifies DOM adapters for non-<table> layouts: a custom-grid of div rows/columns (including a nested grid that must stay isolated), a custom-repeated-grid with duplicate headers, an aria-grid using ARIA roles, and a headerless-grid with no header row. Also covers remount resilience and async row restoration for custom grids.

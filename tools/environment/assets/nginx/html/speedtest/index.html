Speed Test - test prędkości Internetu

Naciśnij START, aby sprawdzić prędkość Internetu. Speedtest zajmie niecałą minutę.

Trwa pomiar prędkości Twojego łącza internetowego. Test zajmie niecałą minutę.

W celu wybrania najlepszego serwera do testu, prosimy o udostępnienie lokalizacji - kliknięcie przycisku "Zezwalaj" w komunikacie przeglądarki.
Lokalizację sprawdzamy tylko podczas testu i wykorzystujemy do tworzenia statystyk i poprawy jakości łączy internetowych.

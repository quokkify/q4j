# Q4J TestRail TestNG

TestNG lifecycle integration for Q4J TestRail.

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/q4j-testrail-testng):

```kotlin
dependencies {
    testImplementation("dev.quokkify:q4j-testrail-testng:0.6.1")
}
```

See the [Q4J module catalog](../../../README.md) for the complete list of modules and common setups.

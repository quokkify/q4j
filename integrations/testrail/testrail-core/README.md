# Q4J TestRail Core

Core TestRail API models and services for test automation.

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/testrail-core):

```kotlin
dependencies {
    testImplementation("dev.quokkify:testrail-core:0.6.2")
}
```

See the [Q4J module catalog](../../../README.md) for the complete list of modules and common setups.

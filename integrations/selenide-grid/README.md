# Q4J Selenide Grid

Selenium Grid support for Q4J Selenide tests.

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/q4j-selenide-grid):

```kotlin
dependencies {
    testImplementation("dev.quokkify:q4j-selenide-grid:0.6.0")
}
```

See the [Q4J module catalog](../../README.md) for the complete list of modules and common setups.

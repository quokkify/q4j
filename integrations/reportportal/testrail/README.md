# Q4J ReportPortal TestRail

TestRail description provider for Q4J ReportPortal reporting.

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/q4j-reportportal-testrail):

```kotlin
dependencies {
    testImplementation("dev.quokkify:q4j-reportportal-testrail:0.2.2")
}
```

See the [Q4J module catalog](../../../README.md) for the complete list of modules and common setups.

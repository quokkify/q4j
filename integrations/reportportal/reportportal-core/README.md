# Q4J ReportPortal Core

Core ReportPortal configuration and API services for Q4J.

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/q4j-reportportal-core):

```kotlin
dependencies {
    testImplementation("dev.quokkify:q4j-reportportal-core:0.6.0")
}
```

See the [Q4J module catalog](../../../README.md) for the complete list of modules and common setups.

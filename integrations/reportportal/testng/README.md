# Q4J ReportPortal TestNG

TestNG listener integration for Q4J ReportPortal reporting.

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/q4j-reportportal-testng):

```kotlin
dependencies {
    testImplementation("dev.quokkify:q4j-reportportal-testng:0.4.0")
}
```

See the [Q4J module catalog](../../../README.md) for the complete list of modules and common setups.

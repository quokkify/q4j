# Q4J Jira TestNG

TestNG integration for Q4J Jira workflows.

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/q4j-jira-testng):

```kotlin
dependencies {
    testImplementation("dev.quokkify:q4j-jira-testng:0.2.3")
}
```

See the [Q4J module catalog](../../../README.md) for the complete list of modules and common setups.

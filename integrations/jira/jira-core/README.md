# Q4J Jira Core

Core Jira client and ticket abstractions for test automation.

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/jira-core):

```kotlin
dependencies {
    testImplementation("dev.quokkify:jira-core:0.7.0")
}
```

See the [Q4J module catalog](../../../README.md) for the complete list of modules and common setups.

# Q4J Jira TMS

Jira ticket source integration for Q4J test management system (TMS) workflows. Depends on [`tms-core`](../../tms/core/README.md).

## Installation

Add the module from [Maven Central](https://central.sonatype.com/artifact/dev.quokkify/jira-tms):

```kotlin
dependencies {
    testImplementation("dev.quokkify:jira-tms:0.15.0")
}
```

See the [Q4J module catalog](../../../README.md) for the complete list of modules and common setups.
